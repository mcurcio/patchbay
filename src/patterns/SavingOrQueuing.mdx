# Saving or queuing changes

An app that queues changes draws each on the canvas, lists them in words with a drop button each,
shows the diff of what the save writes, and has one Save, busy while it runs; the queue keeps only
the net change. The states, from clean to saved or stale, are in
[patterns: saving or queuing changes](https://github.com/mcurcio/patchbay/blob/main/docs/patterns.md#saving-or-queuing-changes).

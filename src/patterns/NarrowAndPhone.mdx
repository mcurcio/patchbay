# Narrow and phone

On a narrow window the inspector is a sheet at the inline end; at phone width it rises from the
bottom; targets and text fields take their touch sizes, and the top bar keeps only the status,
the palette, the theme switch and the inspector. The layout is in
[patterns: narrow and phone layouts](https://github.com/mcurcio/patchbay/blob/main/docs/patterns.md#narrow-and-phone-layouts), and the widths in
[foundations: widths](https://github.com/mcurcio/patchbay/blob/main/docs/foundations.md#widths).

Each example below is drawn in a frame of that width, so the shell takes the layout it would on a
window that wide.

## Crossing a width

The inspector's content is drawn once and moves between the region and the sheet, so a draft
typed into it, and the focus, are still there when the window crosses a width
([`components.md`: AppShell, Narrow windows](https://github.com/mcurcio/patchbay/blob/main/docs/components.md#appshell)).

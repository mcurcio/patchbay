# Editing text

A CodeEditor for text the source reads, its diagnostics marked and listed; a draft is never
overwritten, and goes stale when its own text changes underneath; read-only text says why, and is
never dimmed. The rules are in [patterns: editing text](https://github.com/mcurcio/patchbay/blob/main/docs/patterns.md#editing-text).

## A draft that goes stale

Type in the box, then change the text underneath: the draft is kept, and a `warn` banner offers
Reload, which takes the new text.

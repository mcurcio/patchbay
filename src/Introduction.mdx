# patchbay

The React component library behind the graph editors of ear and rasl. Components only draw: data
comes in as props, and what the person does goes out as callbacks.

The toolbar switches the **brand** (`data-brand` on `<html>`: ear, rasl) and the **theme**
(`data-theme`: system, light, dark); the viewport switch covers the shell's three widths.

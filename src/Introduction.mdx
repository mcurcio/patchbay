# patchbay

A React component library for graph-based editors and live dashboards: design tokens and themes,
primitives, and graph components on React Flow. Components only draw: data comes in as props, and
what the person does goes out as callbacks.

The toolbar switches the **brand** (`data-brand` on `<html>`: none, the base theme, or one of the
example brands in `examples/brands/`) and the **theme** (`data-theme`: system, light, dark); the
viewport switch covers the shell's three widths.
